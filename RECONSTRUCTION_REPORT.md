## 6. Known Limitations

1. **Clustering**: R uses `N2R::Knn` + `igraph::cluster_louvain`; Python uses `sklearn.neighbors.NearestNeighbors` + `leidenalg` (Leiden). Cluster labels differ in ID but partitions should be equivalent (ARI >= 0.95).

2. **NB simulations**: `Excess_variance_ratio_NB` and `Excess_zero_score_NB` use Monte Carlo simulation with different RNG streams in R vs Python. Distributional metrics (KS p-value) should pass; exact p-values differ.

3. **Delaunay triangulation**: R uses `RCDT::delaunay` (unavailable in R 4.5.2); Python uses `scipy.spatial.Delaunay`. Adjacency matrices should be identical.

4. **UMAP**: R uses `uwot::umap`; Python uses `umap-learn` (falls back to sklearn TSNE if unavailable). Coordinates differ by rotation/scaling.

5. **Multi-sample wrappers**: `Compute_variogram_multiple`, `Geary_C_score_multiple` not individually ported — users loop `compute_variogram` / `geary_c_score` per sample.
